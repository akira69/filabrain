Claude compatibility setup
https://api.anthropic.com/v1

In Model & MCP settings, enter the model server URL and API key if required. Use Load models or open Enter a model ID manually. Select Test connection, then Save.

The model selector in chat can switch models on the configured server for that conversation. For server-managed credentials, configure FILABRAIN_MODEL_URL and FILABRAIN_API_KEY. FilaMan uses OIDC_ENC_KEY to encrypt keys saved in the UI.

Ask about materials, print settings, or troubleshooting. Open History to continue a conversation saved in this browser.

Research new filament

Enter a product name or paste a product URL, then select Find specifications. Use the chat input to ask a follow-up. Review the values and their sources before saving.

Manufacturer sources take priority. SearXNG can find additional product pages and datasheets.

Research library

Select up to 50 existing filaments and choose a research mode. Review the results in Research batches.

Research batches

Open a batch, review the sources for each filament, and approve the values you want. Use Apply approved changes to save them.

External MCP

Turn on Enable MCP access in settings and copy the MCP URL. Configure your client for Streamable HTTP on /api/v1/filabrain/mcp. Remote connections use HTTPS.

Send Authorization: Bearer <FilaMan API key>. The key controls access to tools such as find_filaments, research_filament, create_filament and create_spool. Start with find_filaments to verify the connection.

To send proposals to an open editor draft, use Advanced options → Pair a client in the research drawer. Its separate bearer token expires in 15 minutes.

Connect ChatGPT or Claude to FilaMan

Claude custom connectors can use a fixed Authorization header with a FilaMan bearer key. Claude must be able to reach the HTTPS endpoint. Claude connector setup

ChatGPT web requires OAuth for an authenticated MCP connector. FilaBrain's bearer endpoint needs an OAuth adapter for this path. ChatGPT authentication

OpenAI Responses API clients can set the MCP tool's server_url and pass the FilaMan key as its authorization value. Use your OpenAI API key separately to authenticate to the Responses API. OpenAI MCP tool setup
