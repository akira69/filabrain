    Start here

    Ask about materials or print problems in Chat. To add a filament, start with the manufacturer and product name, or paste a product URL in Research new filament.

    Review suggested fields and open their sources before saving. Use Research library to queue up to 50 existing filaments, then review and apply proposals in Research batches.

    Manufacturer sources take priority. A configured SearXNG server lets FilaBrain search more broadly for datasheets, catalogs and alternate sources.

    Under Web search, use Test SearXNG to check that FilaMan can get JSON search results before saving the URL.

    External MCP

    Turn on Enable MCP access in settings and copy the MCP URL. Configure your client for Streamable HTTP on /api/v1/filabrain/mcp. Remote connections use HTTPS.

    Send Authorization: Bearer <FilaMan API key>. The key controls access to tools such as find_filaments, research_filament, create_filament and create_spool. Start with find_filaments to verify the connection.

    To send proposals to an open editor draft, use Advanced options → Pair a client in the research drawer. Its separate bearer token expires in 15 minutes.

    Connect ChatGPT or Claude to FilaMan

    Claude custom connectors can use a fixed Authorization header with a FilaMan bearer key. Claude must be able to reach the HTTPS endpoint. Claude connector setup

    ChatGPT web requires OAuth for an authenticated MCP connector. FilaBrain's bearer endpoint needs an OAuth adapter for this path. ChatGPT authentication

    OpenAI Responses API clients can set the MCP tool's server_url and pass the FilaMan key as its authorization value. Use your OpenAI API key separately to authenticate to the Responses API. OpenAI MCP tool setup
