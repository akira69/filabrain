        Guide

        Model providers
        Recommended hosted setup · OmniRoute setup

        In the OmniRoute dashboard, open Providers → Groq and connect your Groq API key. Groq offers Qwen 3.8 27B on its rate-limited free plan. Create a Groq API key · Groq model · Groq rate limits

        Add http://<omniroute-host>:20128/v1 or your configured HTTPS URL in FilaBrain. Use the OmniRoute endpoint key from its dashboard and select groq/qwen/qwen3.8-27b. Test the connection, save, and choose Make default if you want to start with it.

        In one matched FilaBrain test, Groq and local Qwen 27B returned the same nine specs. Extraction took 1.7 seconds through OmniRoute and 33.9 seconds locally on an NVIDIA V100 with 32 GB of VRAM. Hosted models receive your question and relevant FilaMan context.

        Ollama setup

        Install and start Ollama on the computer running the model. Start with ollama pull qwen3:4b-instruct.

        In FilaBrain, enter http://<ollama-host>:11434/v1 using an address reachable from FilaMan, including from inside its container if applicable. Leave the API key blank for a standard local Ollama server. For a separate machine, use a private network and configure Ollama to listen on it. Ollama network setup

        Load models, pick the model you downloaded, test the connection, and save. Try asking which filament suits an outdoor bracket. Use Sources and inventory to check exact weights, settings, and compatibility. The built-in references are available without SearXNG.

        OpenRouter free tier
        Use https://openrouter.ai/api/v1 and an OpenRouter API key. Select a currently available model with the :free suffix and test the connection.
        OpenAI API setup
        https://api.openai.com/v1
        Use an OpenAI project API key and a text model that supports Chat Completions.
        Claude compatibility setup
        https://api.anthropic.com/v1
        Use a workspace-scoped API key from Claude Console and a Claude model ID. Enter the ID manually if model discovery fails.

        In FilaBrain settings, select Add endpoint to connect another model server. Enter a name, server URL and API key if required. Select Load models or open Enter a model ID manually. Use Test connection before saving.

        Use Models shown in chat to choose which models appear under each endpoint. Chat and interactive research share the model picker. Make default sets the endpoint and model for new conversations and background batches.

        For server-managed credentials, configure FILABRAIN_MODEL_URL and FILABRAIN_API_KEY. FilaMan uses OIDC_ENC_KEY to encrypt keys saved in the UI.

        Install SearXNG with Docker, enable JSON results, and enter its URL under Internet search in settings. Select Test SearXNG before saving. This enables the automatic live-source option under Research sources. Explicit requests to check a known manufacturer page can also work without SearXNG.

        Chat

        Ask which spools in your library suit a job or select a printer and filament for settings. Open Sources and inventory below the answer to check weight, compatibility, and published settings.

        Enable or disable microphone dictation in Settings → Microphone. The microphone dictates an editable draft; press Send when you are ready. It needs HTTPS and a supported browser. Your browser’s speech service may send audio online for transcription; FilaBrain sends only the resulting text to the chat model when you press Send. OS keyboard dictation works independently, including when the FilaBrain microphone is disabled.

        Printer and filament preloads your saved choices. If there is one active printer, it is selected automatically. Compatible printer plugins can provide a loaded-filament suggestion through FilaMan; confirm the suggestion before using it. Select the nozzle yourself.

        For endpoint transcription, edit a connection in Model settings and enable Audio transcription. Enter a model that supports the standard /audio/transcriptions API. Enable Chat too if this connection also serves chat models; the two model IDs are separate. Existing endpoints start with Chat only.

        Under Microphone → Dictation source, choose Browser dictation or an audio endpoint. Endpoint mode sends your recording through FilaMan to that endpoint when you stop recording; it never falls back to a different service. Recordings are limited to 60 seconds and converted to WAV. FilaBrain does not save the audio. Review the transcript before pressing Send. The endpoint may have its own retention and billing policies.

        Tap the context ring to see tokens reported for the last model request, including instructions, sources, and the reply. A percentage appears only when the active context limit is known. Ollama can report its running model’s window; other endpoints may report token counts without a limit.

        Ask for a spool’s empty weight or dimensions to compare catalog matches and photos. Select the reel that matches yours to keep the choice in this conversation.

        Printing references and catalogs work with a local model when the Internet is unavailable. With SearXNG configured, known manufacturer pages and datasheets are checked automatically for product and printer questions. You can turn automatic checks off under Research sources in settings. SearXNG can find additional sources. Use the conversation name and caret above the chat to switch between conversations saved in this browser. Switching workspace tabs keeps your draft and lets replies finish.

        Build the complete draft here. Details lets you create a missing manufacturer or palette swatch. Standard color previews let you reuse a swatch or create one from a RAL/Pantone screen preview while keeping the manufacturer’s color name. RAL and Pantone previews use their own publisher sources. Shared swatch names include the standard code; the filament keeps the manufacturer’s name. If the preview is unavailable, no HEX is guessed. Existing swatches are not renamed or recolored automatically. Creating a manufacturer or swatch adds it to your library immediately; the filament is saved only after you review and confirm it.

        Research new filament

        Use Find spool specs in a new or existing filament. Choose a matching reel to review its empty weight, outer diameter, and width before saving. If the filament already links to a FilaManDB spool profile, FilaBrain shows its photo when available.

        Enter an SKU, product link, or what you know, such as “Paramount 3D PLA purple,” then select Find specifications. Review candidate identities and source links before choosing a product. Similar SKUs need your confirmation; use Details to correct a conflicting clue. Choosing a candidate researches a draft; nothing is saved until you review and save it. Use the chat input to ask a follow-up.

        Manufacturer sources take priority. Live and bundled catalogs can provide candidates when product pages are unavailable. A source product code may identify a retailer listing; it is kept separate from a verified manufacturer SKU. Choosing a candidate can replace an inferred search clue, while explicit Details fields remain constraints. SearXNG can find additional product pages and datasheets.

        Research this filament

        The filament link opens the same workspace as the sidebar. Chat uses the current filament as context. In Filament, choose Current filament to stage reviewed changes into the open editor, or New filament to work on a separate creation draft. Switching targets preserves each draft and conversation. Palette staging requires a FilaMan host that advertises this support; older hosts still show the color sources and previews.

        Select Find specifications to check sources. Review the evidence and stage the fields you want, then save in the FilaMan editor. Use the conversation selector above the chat to see earlier findings without searching again.

        Research library

        Select up to 50 existing filaments and choose a research mode. Review the results in Research runs.

        Color audit checks explicit RAL/Pantone references and manufacturer color names. Review the official publisher preview and suggested shared swatch name. A shared rename changes the name everywhere that swatch is used; the confirmation shows the affected-filament count. It leaves HEX, assignments and manufacturer color names unchanged. Keep, reuse or create a swatch separately to change only the selected filament’s preview. Existing saved codes are identified as saved references; a manufacturer-name correction needs product evidence. Confirming a rename saves that shared name immediately. Use Done & next to mark a color-only result Reviewed without applying inventory changes. No colors are merged or recolored automatically.

        Add spool

        Choose Spool link to check a tag for a linked spool, or Filament details to read the product from the scale. After reading the details, verify the spool link or choose Find filament for a new spool. You can also search by label, SKU, or product URL.

        Review the match and save the spool in FilaMan. Use the scale to link the tag and record its weight.

        Research runs

        Open a research run, review the sources for each filament, and approve the values you want. Use Apply approved changes to save them.

        FilaMan MCP

        If you used FilaBrain’s separate MCP endpoint, switch your client to FilaMan’s built-in /mcp from /api/v1/filabrain/mcp. Replace the old Bearer header with Authorization: ApiKey <FilaMan API key>. Use HTTPS for remote connections.

        Enable AI Assistants (MCP) in FilaMan’s app settings and copy the connection template for your client. Use list_filaments to check the connection. Inventory changes require Allow write access and the matching permissions.

        For external research on FilaMan 2.2.2 or newer, add filabrain-research_filament to MCP_PLUGIN_READ_TOOLS and restart FilaMan. The tool requires filaments:read and returns suggestions and sources to your MCP client for review.
